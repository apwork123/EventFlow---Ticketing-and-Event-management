# Online Event Management System

Panel: J  
A event website for ticket booking for users and dashboard for event organizers.

![angif](https://github.com/user-attachments/assets/13c2df86-6aec-43f3-9fc3-206874a85bd4)



#### Build and Run:

Clone the repository and switch to main branch:

```bash
git clone https://github.com/apwork123/FSD_Mini_Project.git
```

```bash
git switch main
```

```bash
cd front-end
```

Install dependencies and run dev server:

```bash
npm install
```

```bash
npm run dev
```
